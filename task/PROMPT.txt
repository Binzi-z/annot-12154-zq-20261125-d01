在原生 Windows 上用 Python 3.12 标准库实现本地离岗访问回收审计器。输入为合成角色继承、授权绑定、离岗和撤销事件。事件有生效时刻与入账序号，查询固定水位且角色图可能有环。撤销一条来源时，必须保留仍有其他来源的有效访问，并报告导致变化的最短证据链。维护增量证据与受影响主体集合，对不相连的子图保持缓存，旧水位保持可重放。用独立小图穷举合法路径，与随机顺序加删边、离岗和迟到重授的快照逐次核对，验证环不会自证且等长见证稳定排序。数据和结果均留在工作区，交付 CLI 和说明，统一用 `python -B -m unittest discover -s tests -v` 运行核心验收。
